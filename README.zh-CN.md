# Secret Guard

[English](README.md) | **简体中文**

一个请求处理插件，用来防止密钥随模型流量泄露。它识别用户粘贴进提示词中的 API 密钥、访问令牌、私钥和密码，按设置拒绝请求，或在请求发往上游之前遮盖每个密钥。它也检查模型的回答，模型复述上下文中的密钥时不会以明文返回给用户。

- 高置信度的密钥（带已知前缀的厂商密钥、私钥块、出现在密钥 ID 旁边的云厂商密钥）默认拦截。
- 常被有意粘贴的标识和令牌（密钥 ID、JWT、数据库连接串密码、OpenAI 兼容服务的 `sk-` 密钥）默认遮盖。
- `password=`、`secret:` 等名称之后看起来随机的值默认仅记录。
- 每个检测器都可设为拦截、遮盖、仅记录或关闭；可设置白名单；可用自定义正则表达式增加检测器。
- 日志中从不出现密钥本身：检测结果只记录检测器名称，以及可选的密钥 SHA-256 前 8 位十六进制。

需要 new-api v1.0.0-rc.50 及以上版本（支持请求处理插件）。插件没有渠道部分：它不是渠道类型，也不需要任何厂商账号或密钥。

## 安装

1. 在管理后台打开插件页面，从社区市场安装本插件，或上传 `plugin.js`。
2. 启用插件。插件总开关只影响任务插件和 Provider 插件渠道；只要有启用的实例匹配，请求处理就会运行。

## 添加实例

实例在请求插件设置中管理。每个实例是插件的一份配置，各有自己的设置：

- 全局：对所有请求生效，适合作为全站策略。
- 分组：只对所列用户分组的请求生效，例如为 `team` 分组设置更严格的策略。
- 模型：把实例限定在所列模型上，按客户端请求的模型名匹配；留空表示所有模型。
- 渠道绑定：渠道在自己的请求插件设置中列出实例 ID，这些实例只在该渠道上运行，检查为其上游构建的请求体。适合只保护流量离开内网的渠道。

运行顺序为：全局实例，然后分组实例，最后渠道绑定的实例。可以同时运行本插件的多个实例，例如一个全局的仅记录实例，再加一个只对某个分组拦截的实例。

每个实例在 ingress 阶段（计价之前）检查一次请求，因此被拦截的请求既不计费也不会发出。渠道绑定的实例在每次渠道尝试时检查为该渠道构建的请求体。回答检查在产生回答的那次尝试上运行。

## 检测器

| 检测器 | 识别内容 | 默认 |
| --- | --- | --- |
| `private_key` | PEM 私钥块：RSA、EC、DSA、OpenSSH、PKCS#8、加密私钥和 PGP，也包括经过 JSON 转义的（粘贴的服务账号文件）和缺少 END 行的私钥 | 拦截 |
| `openai_api_key` | OpenAI 项目、服务账号、管理员密钥以及旧版用户密钥 | 拦截 |
| `anthropic_api_key` | Anthropic API、管理员和 OAuth 密钥 | 拦截 |
| `google_api_key` | Google API 密钥、OAuth 客户端密钥和 OAuth 访问令牌 | 拦截 |
| `aws_access_key_id` | AWS 访问密钥 ID（AKIA、ASIA、ABIA、ACCA） | 遮盖 |
| `aws_secret_access_key` | 出现在访问密钥 ID 附近，或 `aws_secret_access_key` 等名称之后的 40 位 AWS 秘密访问密钥 | 拦截 |
| `github_token` | GitHub 个人、OAuth、应用、刷新令牌和细粒度令牌 | 拦截 |
| `gitlab_token` | GitLab 个人、部署、Runner、触发器等带前缀的令牌 | 拦截 |
| `slack_token` | Slack 机器人、用户、应用和配置令牌以及传入 Webhook 地址 | 拦截 |
| `stripe_live_key` | Stripe 正式环境的私密密钥、受限密钥和 Webhook 签名密钥；测试密钥不报告 | 拦截 |
| `other_api_token` | Hugging Face、xAI、Groq、npm、PyPI 和 SendGrid 令牌 | 拦截 |
| `alibaba_access_key_id` | 阿里云 AccessKey ID（LTAI） | 遮盖 |
| `alibaba_access_key_secret` | 出现在 AccessKey ID 附近，或 `AccessKeySecret` 等名称之后的 30 位 AccessKey Secret | 拦截 |
| `tencent_secret_id` | 腾讯云 SecretId（AKID） | 遮盖 |
| `tencent_secret_key` | 出现在 SecretId 附近，或 `TENCENTCLOUD_SECRET_KEY` 等名称之后的 32 位 SecretKey | 拦截 |
| `jwt` | 头部和载荷都能解码为 JSON 对象的已签名 JSON Web Token | 遮盖 |
| `db_connection_string` | 带 `user:password@` 的 PostgreSQL、MySQL、MariaDB、MongoDB、Redis、AMQP、SQL Server、ClickHouse、CockroachDB 和 JDBC 连接串中的密码 | 遮盖 |
| `generic_sk_key` | 其他由 32 到 64 位字母数字组成的 `sk-` 密钥，许多 OpenAI 兼容服务和网关签发这种密钥 | 遮盖 |
| `generic_assignment` | `password`、`secret`、`api_key`、`access_token`、`client_secret`、`private_key` 或 `token` 后接 `=` 或 `:` 时，后面看起来随机的值 | 仅记录 |

每个检测器都要求已知前缀或结构，并做形态检查：字符看起来随机、长度正确、JWT 可以解码、私钥正文至少 64 个 base64 字符、云厂商密钥同时含大写、小写和数字且熵足够高。识别到数据库连接串时只遮盖其中的密码，连接串的其余部分仍可帮助模型理解问题。

## 设置

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 检测器处理方式 | 见上表 | 每个检测器单独设置：拦截会拒绝请求；遮盖会在发送前把密钥替换为 `[REDACTED:检测器名]`；仅记录只记一条检测结果，请求原样发送；关闭则跳过该检测器。 |
| 回答检查 | 遮盖 | 遮盖：所有未关闭且非仅记录的检测器在回答中都以 `***` 遮盖。按检测器处理方式：沿用检测器设置，拦截类检测器会停止回答。仅记录：只记录回答中的检测结果。关闭：不检查回答。 |
| 白名单 | 空 | 每行一个永不视为密钥的值。以 `*` 结尾表示前缀匹配，例如 `sk_test_*`。以 `#` 开头的行是注释。最多 1000 条。比较的是会被遮盖的部分：密钥本身，或数据库连接串中的密码。 |
| 忽略占位符和文档示例 | 开启 | 跳过 `xxxx`、`your-api-key`、`${DB_PASSWORD}`、`user:password@`、含 `EXAMPLE` 的 AWS 密钥以及 jwt.io 示例令牌等值。关闭后这些值也会报告。 |
| 自定义检测器 | 无 | 最多 20 个正则表达式，每个包含名称（小写字母、数字、`.`、`-`、`_`）、处理方式和是否忽略大小写。以 `(?i)` 开头同样表示忽略大小写。含捕获组时只把第一个捕获组视为密钥。无法编译或能匹配空文本的表达式在保存实例时会被拒绝。 |
| 赋值内容的最小熵 | 3.5 | `generic_assignment` 的值需要达到的每字符香农熵（比特）。短值达不到高熵，因此阈值不超过 log2(长度) - 0.5。 |
| 检查附带的文档 | 关闭 | 同时通过网关读取请求附带的文本、PDF 和 DOCX 文件。完整读取的纯文本文件会就地遮盖；PDF、DOCX 或被截断的文件含有需要遮盖的密钥时拒绝请求，因为网关无法改写这些文件。 |
| 每个请求检查的文本量 | 2,000,000 字符 | 超出部分的字符串不检查，并记为检测结果 `scan_limit`，类别为 `unscanned`。 |
| 记录指纹 | 开启 | 在管理员日志的规则名中附加每个密钥 SHA-256 的前 8 位十六进制，例如 `github_token:1a2b3c4d`，便于识别多次请求中泄露的是同一个密钥。 |
| 拒绝提示 | 见下文 | 请求被拦截时返回给客户端的消息；`{detectors}` 会替换为检测器名称。网关会在末尾追加 `(code: secret_guard.blocked)`。 |

默认的拒绝提示为："The request contains what looks like a credential ({detectors}). Remove it or replace it with a placeholder and try again."

## 客户端和日志看到什么

- 被拦截的请求返回 HTTP 400，错误码 `request_rejected`，内容为拒绝提示。请求不计价、不计费，也不会转发到其他渠道。
- 被遮盖的请求在发往上游时，每个密钥都替换为 `[REDACTED:检测器名]`；用户日志中会显示密钥已被遮盖的说明。
- 回答中被遮盖的密钥显示为 `***`（网关固定的遮盖文本）。在「按检测器处理方式」模式下，拦截类检测器会停止回答：非流式回答变为 HTTP 400 `response_rejected`，流式回答以错误事件结束。计费按网关对被停止回答的规则处理。
- 用户日志按类别和次数列出检测结果；管理员步骤日志另外列出规则名，开启指纹时附带指纹。任何日志、消息或说明中都不包含匹配到的值。

示例：用户发送 `Bearer` 加一个 JWT，以及一个带密码的 PostgreSQL 连接串。上游收到的是 `Bearer [REDACTED:jwt]` 和 `postgres://app:[REDACTED:db_connection_string]@db.internal:5432/app`，用户日志显示检测结果 `jwt` 和 `db_connection_string` 各一次。

## 设计取舍

- 失败处理：插件没有声明 `optional`。钩子出错时（例如自定义正则表达式超出 5 秒的钩子时限），请求以 HTTP 500 `request_plugin_failed` 失败，而不是不经检查直接发出。安全过滤器悄悄失效比报错更糟。请让自定义表达式保持简单、有界。
- 检查位置：请求在 `ingress` 阶段检查，因此被拦截的请求不会计价或计费，遮盖后的请求体就是后续所有阶段、重试和渠道看到的内容。插件不检查 `egress`：渠道自己的参数覆盖可能有意加入凭据，例如放在请求体中的上游密钥。
- 读取范围：JSON 请求体中的所有字符串，包括系统提示词、工具定义、工具调用参数和工具结果；网关保护的成员除外（`model`、`stream`、`stream_options`、`n`、`generationConfig`、`size`、`quality`、`resolution`、`seconds`、`duration`、`service_tier`，以及 Midjourney 提交中的 `action`、`customId` 和 `content`）。内联图片和文件从不传给插件。
- 流式回答：回答检查会保留每路输出的最后一个词以及其前面最多 64 个字符，因此跨分片的密钥会被整体遮盖。不含密钥的回答大约延迟一个词。
- 性能：每个表达式都以固定前缀开头，所有重复次数都有上限，每个检测器先做一次低成本的前缀检查。在测试网关上，1.5 MB 的请求端到端耗时约 0.3 秒。

## 限制

- 回答检查覆盖 Chat Completions、Responses、Claude Messages 和 Gemini generateContent（流式或非流式），以及 Responses WebSocket 和 Realtime 的文本。推理内容、工具调用参数、拒答内容，以及以分段数组形式给出的 Chat Completions 内容，网关不会交给插件检查。图片、音频、向量、重排序和任务结果不检查。
- 请求检查覆盖网关交给请求处理的所有接口；二进制和 URL 编码的请求体、音频输入以及文件内容（未开启「检查附带的文档」时）不检查。
- 流式回答中超过 8192 个字符的私钥，可能在 END 行到达前已部分发出；回答末尾被截断的私钥会遮盖到其 base64 行的末尾。
- 回答中的遮盖文本固定为 `***`，不能自定义。
- 需要遮盖超过 512 个字段的请求会以 `secret_guard.too_many_secrets` 拒绝，因为网关最多接受 512 个补丁操作。
- 同一个字符串里既有需要遮盖的密钥又有内联媒体引用时会拒绝请求，因为网关无法修改这样的值。

## 误报与漏报

误报及处理方法：

- 带已知前缀的测试或示例密钥：加入白名单（`sk_test_*`、完整密钥或前缀）。
- 开启「忽略占位符」时跳过文档示例值。真实密钥中恰好含有 `example`、`xxxx`、连续 6 个相同字符或 `1234567890` 时也会被跳过。
- `jwt` 和 `generic_sk_key` 也会匹配用户有意分享的短期令牌或自签令牌，因此默认是遮盖而不是拦截。
- `generic_assignment` 会报告单元测试中 `password = "Summer2024!"` 这样的代码，因此默认仅记录。标识符、带点的名称和函数调用（`hashedPassword`、`os.environ.get(...)`）不报告。
- AWS 密钥 ID 附近的 40 位 base64 字符串，或阿里云、腾讯云密钥 ID 附近的 30 位、32 位字母数字串，只要同时含大写、小写和数字，就被视为秘密密钥。十六进制摘要不会被视为密钥。

漏报及未覆盖的情况：

- 没有已知前缀或结构的密钥：散文中的密码、会话 Cookie、上表之外的厂商密钥。可使用自定义检测器或 `generic_assignment`。
- 被空格或换行拆开、经过编码（base64、连接串之外的 URL 编码）或由用户逐字拼写的密钥。
- 距离密钥 ID 超过 256 个字符且不在已知名称之后的云厂商密钥。
- 密码中含未编码 `@` 或 `/` 的数据库连接串，以及作为查询参数给出的密码。
- 超出每个请求检查量的文本、未开启「检查附带的文档」时的文件、被截断文件的后半部分，以及网关不交给回答检查的输出。
